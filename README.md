# Week 4 - Hands On Coffee Finder App

## Learning Objectives Covered

**CO5** Develop an Android project with a ListView, displaying arrays using an ArrayAdapter, implementing decision structures like Switch statements, and utilizing intents to launch external applications such as a browser.

## Project Prompt

In this project, you will work on the **Coffee Finder App**. The purpose of the app is to help users find four great coffee spots in your town.

## Instructions

### Main Screen
- Display the names of four coffee shops.

### Details Screen
- Show the name, address, and an image/logo of the selected coffee shop.

## Requirements

- Use your own images.
- Create a custom launcher icon.
